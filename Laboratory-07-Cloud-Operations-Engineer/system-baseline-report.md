# System Baseline Report

## 1. Memory (RAM) Usage

The `free -h` command was used to check the server's memory usage.

- **Total RAM:** 1.9 GiB
- **Used Memory:** 419 MiB
- **Available Memory:** 1.4 GiB

## 2. Disk Storage

The `df -h /` command was used to check the storage capacity of the root (`/`) file system.

- **Total Storage Capacity:** 19 GB
- **Used Storage:** 5.5 GB
- **Available Storage:** 13 GB
- **Disk Usage:** 30%

## 3. Importance of Checking Disk Space

Checking disk space before a massive traffic surge is important because the server needs enough storage for application files, logs, and temporary data to avoid storage-related problems and service interruptions.
