# Mission 9 Reflection – Cloud Automation Engineer

## 1. Importance of Automation

Automation is important when managing hundreds of cloud servers because it reduces repetitive manual work, saves time, and makes tasks more consistent. Instead of manually backing up every server, an administrator can use scripts and scheduled tasks to perform backups automatically.

## 2. Risks of Automation

One danger of automation is that a small mistake in a script can affect many servers at once. For example, an incorrect command could delete important files or overwrite data across multiple systems. To reduce these risks, scripts should be tested carefully, permissions should be limited, and backups should be verified before automation is deployed widely.

## 3. Bash Script vs. Docker Compose YAML

A Bash script contains shell commands that execute tasks in sequence, such as creating directories and compressing files. Docker Compose YAML, which I encountered in the earlier cloud-native mission, describes how application services and containers should be configured. Bash is useful for automating system tasks, while Docker Compose is useful for defining and managing multi-container applications.
