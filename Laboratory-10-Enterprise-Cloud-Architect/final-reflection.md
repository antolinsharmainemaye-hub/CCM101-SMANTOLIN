# Final Reflection – The Enterprise Cloud Architect

This laboratory activity helped me understand more about how cloud infrastructure operates and how different technologies work together to create and maintain a cloud-based system. During this activity, I successfully set up my own cloud storage platform using Nextcloud and MariaDB on an Ubuntu Server virtual machine through Oracle VM VirtualBox. I also learned that Docker and Docker Compose make application management easier by allowing different services to run and work together in separate containers.

One important lesson I gained from this activity is the need for proper configuration when building a cloud environment. I needed to ensure that the virtual machine was running properly, the network settings were correct, and the Nextcloud and MariaDB containers were able to communicate with one another. Some parts were difficult at first, especially setting up the services and accessing Nextcloud through my Windows browser. Despite these challenges, I carefully followed the steps and checked the configurations until I was able to run the system successfully.

Aside from deployment, I also learned how to protect and maintain the server. I set up the UFW firewall to manage incoming connections and understood why database services should not be directly exposed to outside access. I also created a Bash backup script and used Cron to schedule automatic backups. Through this process, I realized that automation helps reduce repetitive manual work and that keeping backup copies is important to prevent data loss. I also tested data persistence by restarting the Nextcloud containers and checking that the file I uploaded was still saved.

This activity taught me that creating a cloud system involves more than just installing and running an application. It also requires attention to networking, security, data storage, backups, and system maintenance. I was able to see how these different parts work together to keep the platform running properly. Even though I faced a few difficulties during the process, I learned from them and became more comfortable using Linux commands, Docker, and basic server administration.

For future improvements, I would like to make the system more secure by adding HTTPS, keeping backup copies in a separate storage location, and improving the backup script by including additional checks to ensure that the backups are successful. These changes could help improve the overall security and reliability of the system.

In conclusion, this laboratory activity gave me useful hands-on experience in applying the concepts of virtualization, containerization, cloud computing, security, and automation. It helped me understand how a cloud storage platform is set up and maintained, while also improving my confidence in working with different server technologies.
