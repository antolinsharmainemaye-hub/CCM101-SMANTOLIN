# Cloud Infrastructure Components

## Compute Resources

**Example:** CPU

The CPU is responsible for processing instructions and running applications and services. Compute resources are important in cloud computing because they provide the processing power needed to perform tasks and run workloads. In the KillerCoda Linux environment, the CPU information was inspected using Linux commands such as `lscpu`, which helped identify the available processor resources of the cloud server.

## Storage Resources

**Example:** Disk Storage

Storage is used to save the operating system, applications, files, and other data. It is important in cloud computing because applications and services need reliable storage to keep and access information. In the KillerCoda Linux environment, disk storage and file systems were investigated using commands such as `lsblk` and `df -h` to identify available storage and disk usage.

## Networking Resources

**Example:** Network Interface and IP Address

Networking allows the cloud server to communicate with other systems and connect to the Internet. It is important in cloud computing because cloud resources need network connectivity to communicate with users, applications, and other services. In the KillerCoda Linux environment, the network interfaces and IP address were examined using the `ip addr` command.

## Operating System

**Example:** Linux

The operating system manages the computer's hardware and provides an environment where applications and services can run. It is important in cloud computing because cloud servers need an operating system to manage resources and support applications. The KillerCoda Playground provided a Linux-based cloud server, and commands such as `cat /etc/os-release` and `uname -r` were used to identify the operating system and kernel version.
