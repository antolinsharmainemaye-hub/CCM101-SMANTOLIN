# Mission 2 – Reflection

This laboratory activity helped me understand the basic components of cloud infrastructure and how they work together. Among the different components, I think compute is one of the most important because it provides the processing resources needed to run applications and services. Without compute resources, applications would not be able to operate properly even if storage and networking resources are available. I also learned how Linux supports cloud computing by providing a reliable environment for running and managing cloud servers. Using the Linux terminal, I was able to investigate the operating system, kernel, CPU, memory, storage, networking information, and other resources available in the cloud environment.

Technical documentation is also important before deploying infrastructure because it provides a clear record of the resources, configurations, and decisions involved in a project. Proper documentation can help cloud engineers understand the infrastructure, troubleshoot possible problems, and maintain the system more efficiently. During this laboratory activity, I learned new skills such as using Linux commands to investigate a cloud server, identifying different cloud infrastructure components, and comparing similar services offered by AWS, Microsoft Azure, and Google Cloud Platform. I also improved my skills in creating Markdown files, organizing technical information, creating a simple cloud infrastructure diagram, and managing project files using GitHub.

After completing this mission, my GitHub portfolio became more organized and complete because I added a new laboratory folder containing technical documentation, infrastructure information, cloud service comparisons, a reflection, and a cloud architecture diagram. Overall, this activity improved my understanding of cloud computing and gave me practical experience with Linux, cloud infrastructure, technical documentation, and GitHub. These skills will be useful in future cloud computing activities and projects.
