## Major Cloud Providers

The three major public cloud providers—Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP)—offer similar core infrastructure services, although they use different names and provide different features.

| Infrastructure Component                 | AWS                                      | Microsoft Azure                 | Google Cloud Platform                      |
| ---------------------------------------- | ---------------------------------------- | ------------------------------- | ------------------------------------------ |
| **Compute**                              | Amazon EC2                               | Azure Virtual Machines          | Compute Engine                             |
| **Storage**                              | Amazon S3                                | Azure Blob Storage              | Cloud Storage                              |
| **Networking**                           | Amazon VPC                               | Azure Virtual Network (VNet)    | Virtual Private Cloud (VPC)                |
| **Identity and Access Management (IAM)** | AWS Identity and Access Management (IAM) | Microsoft Entra ID / Azure RBAC | Cloud Identity and Access Management (IAM) |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

Amazon Web Services (AWS) is widely recognized for offering one of the broadest and most mature portfolios of cloud services. It provides a large variety of services covering computing, storage, networking, databases, security, analytics, AI, IoT, and many other areas.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be the recommended platform because it integrates well with Microsoft products and technologies such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise solutions. This integration can make identity management, administration, and migration easier for organizations already using Microsoft's ecosystem.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform (GCP) is widely recognized for its strong capabilities in Artificial Intelligence and Machine Learning, as well as its Kubernetes technology. Google created Kubernetes, making GCP a strong choice for organizations working with containers and cloud-native applications.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent core infrastructure services for compute, storage, networking, and identity and access management. They also provide scalable, on-demand cloud resources and additional services for databases, security, analytics, artificial intelligence, and application development.
