# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services for computing, storage, databases, networking, security, analytics, and application development. AWS allows organizations to access IT resources on demand without having to maintain their own physical infrastructure. AWS began offering cloud infrastructure services in 2006 and is used by businesses, startups, government organizations, and other institutions worldwide. 

## Global Infrastructure

AWS has a global infrastructure made up of Regions and Availability Zones. An AWS Region is a separate geographic area where cloud resources are hosted, while Availability Zones are isolated locations within a Region. These locations help organizations build applications that are highly available and reliable. AWS also provides Local Zones and Wavelength Zones to place resources closer to users and support applications that require low latency.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can use the console to create, configure, monitor, and manage cloud resources such as virtual machines, storage, databases, and networks. The console also allows users to select an AWS Region and access different services from one centralized interface.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers that can be used to run applications and workloads in the cloud.

2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for storing files, documents, images, videos, backups, and other data.

3. **Amazon RDS (Relational Database Service)** – Provides managed relational databases that organizations can use without managing the underlying database infrastructure themselves.

4. **Amazon VPC (Virtual Private Cloud)** – Allows users to create and manage a virtual network where AWS resources can securely operate.

## Three (3) Advantages

1. **Scalability** – AWS allows organizations to increase or decrease computing resources based on their workload and business needs.

2. **Global Availability** – AWS provides infrastructure in different geographic Regions and Availability Zones, allowing organizations to deploy applications closer to their users.

3. **Cost Efficiency** – AWS uses a pay-as-you-go model for many services, which can reduce the need for large upfront investments in physical hardware and infrastructure.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for hosting websites and mobile applications, storing and backing up large amounts of data, running business applications, and managing databases. Organizations can also use AWS for data analytics, artificial intelligence and machine learning, disaster recovery, and global application deployment. Its wide range of services allows businesses to build and scale their IT infrastructure according to their requirements.
