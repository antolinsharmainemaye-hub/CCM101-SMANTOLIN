# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform offered by Google. It provides services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, and application development. Organizations can use GCP to create, deploy, and manage applications and other workloads using Google's cloud infrastructure.

## Global Infrastructure

Google Cloud has a worldwide infrastructure made up of Regions and Zones. Regions represent geographic areas, while Zones are separate locations within a Region where cloud resources can be deployed. This structure helps organizations improve application availability, reliability, and performance by placing resources closer to their users.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Through the console, users can create and manage virtual machines, storage, networks, databases, applications, and other cloud resources. It also provides tools for monitoring resources, managing permissions, and checking cloud usage and costs.

## Four (4) Core Services

| GCP Service | Category | Description |
|---|---|---|
| Compute Engine | Compute | Provides virtual machines that can be used to run applications and different workloads in the cloud. |
| Cloud Storage | Storage | Provides scalable object storage for files, images, videos, backups, and other types of data. |
| Virtual Private Cloud (VPC) | Networking | Provides a virtual network for securely connecting and managing Google Cloud resources. |
| Google Kubernetes Engine (GKE) | Container Management | Provides a managed environment for deploying and managing containerized applications using Kubernetes. |

## Three (3) Advantages

1. **Strong AI and Machine Learning Capabilities** – GCP provides services and infrastructure that support the development and deployment of artificial intelligence and machine learning applications.

2. **Global Network and Infrastructure** – Google Cloud operates across many geographic locations, allowing organizations to deploy applications closer to users and improve performance and availability.

3. **Scalable Cloud Resources** – GCP allows organizations to adjust their computing, storage, and other cloud resources based on their changing workload requirements.

## Typical Enterprise Use Cases

Google Cloud Platform can be used by enterprises for:

- Hosting websites and business applications
- Running virtual machines and cloud workloads
- Storing and managing business data
- Developing artificial intelligence and machine learning applications
- Analyzing large datasets
- Deploying containerized applications using Kubernetes
- Developing and testing software
- Building scalable web and mobile applications
- Backup and disaster recovery
- Managing global applications and services
