# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud platform that provides various online services for organizations and developers. It supports computing, data storage, networking, databases, security, analytics, artificial intelligence, and application development. Through Azure, businesses can build new applications or transfer their existing systems and workloads to cloud-based infrastructure.

## Global Infrastructure

Azure has a worldwide cloud infrastructure located in many geographic areas. Its infrastructure is divided into Regions, and selected Regions include Availability Zones for additional reliability. By using these locations, organizations can place their applications and resources nearer to their users while maintaining dependable cloud operations.

## Cloud Management Console

The Azure Portal serves as the main web-based interface for managing Microsoft Azure resources. Users can use the portal to deploy and control virtual machines, storage, networks, databases, security features, subscriptions, and costs. It provides a single platform where different Azure resources can be monitored and configured.

## Four (4) Core Services

| Azure Service | Category | Description |
|---|---|---|
| Azure Virtual Machines | Compute | Provides cloud-based virtual machines that can run applications and various operating systems. |
| Azure Blob Storage | Storage | Stores large volumes of unstructured information, including files, images, videos, and backups. |
| Azure Virtual Network | Networking | Creates private network environments and enables secure communication between Azure resources. |
| Microsoft Entra ID | Identity & Security | Manages user identities and controls access to applications and organizational resources. |

## Three (3) Advantages

1. **Strong Microsoft Compatibility** – Azure works effectively with Microsoft products and technologies that are widely used by organizations.

2. **Flexible Resource Management** – Azure allows businesses to increase or reduce their resources depending on their workload and operational needs.

3. **Worldwide Infrastructure** – Azure has cloud facilities in different parts of the world, helping organizations provide reliable services to users in various locations.

## Typical Enterprise Use Cases

Microsoft Azure is commonly used by organizations for:

- Deploying websites and business applications
- Hosting Windows and Linux-based virtual machines
- Managing company files and backup data
- Building and maintaining cloud databases
- Developing and testing software applications
- Performing data analytics and AI workloads
- Implementing backup and disaster recovery solutions
- Supporting hybrid cloud infrastructure
- Moving existing business systems to the cloud
